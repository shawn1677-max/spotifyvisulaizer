Audio source

Spotify's Web Playback audio is DRM-encrypted and cannot be tapped for FFT. The analysis stream gives beats, bars, sections, pitches and timbre. For real FFT, route system audio into a virtual mic (BlackHole) and pick "Mic".

One-time setup

Aurora is a static page — there is no shared backend. Spotify requires every user to register their own free developer app. Takes about 90 seconds.

  1. Go to developer.spotify.com/dashboard and log in.
  2. Click Create app. Name it anything (e.g. "Aurora"). Description: anything.
